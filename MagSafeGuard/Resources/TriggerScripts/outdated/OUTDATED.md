# Outdated trigger scripts

These shell scripts duplicate **built-in network actions** in Settings → Security → Network. They are kept for reference and manual use only.

**Not installed** by “Install bundled scripts…” in the app.

| Script | Use built-in action instead |
| --- | --- |
| `clear-clipboard.sh` | Clear Clipboard |
| `cryptomator-umount-best-effort.sh` | Unmount Cryptomator |
| `disable-bluetooth-best-effort.sh` | Disable Bluetooth |
| `eject-removable-volumes.sh` | Eject Removable Volumes |

To run one manually: copy to `~/.magsafe/scripts/`, `chmod 700`, add the path under Settings → Advanced → Custom Scripts.
